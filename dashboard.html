What's New

A short guide to what's currently available in the beta

Beta · October 31, 2026
Focused calendar and refreshed profile

The calendar now opens on today and shows upcoming dates only, with roadmap activities and personal reminders displayed directly inside their calendar days. Removed the separate roadmap banner, test countdown panel, and duplicate upcoming-activities list to reduce scrolling and visual clutter. The candidate profile now uses QuickRN's shared navy-and-teal brand system, a cleaner layout, simpler navigation, and a more focused analytics reset area.

Cleaner, more focused dashboard

The dashboard has been reorganized into a compact study overview with four key metrics, a smaller NCLEX readiness indicator, and a subtle line graph showing saved exam performance over time. Client Needs priorities remain visible beside the graph, with detailed breakdowns available in Analytics. Subjects, lessons, and the Clinical Study Coach are now grouped in a dedicated Learning Center. The trend graph recognizes saved exam attempts using their completion timestamps; missing passing estimates are left blank rather than shown as zero. This redesign changes the presentation while preserving existing study tools and exam-history actions.

Expanded Learning Center

Removed the repeated Learning Center title inside its own tab. Added subject- and topic-based video search with up to four popular free results and embedded YouTube playback in QuickRN. Added personalized printable flashcards using measured weak Client Needs areas and available browser-saved notes. The local flashcard generator does not require an API key and does not send notes to an external AI service. The study roadmap now ranks measured weak Client Needs areas from lowest accuracy upward before on-track areas.

Streamlined exam feedback and question layout

Removed the separate “Report this item” action and combined issue reporting with the Feedback control, including issue categories and question context. The Check Answer action is right-aligned. Items without a case study no longer show an empty Clinical Record; their question stem moves to the left pane while answer choices remain on the right.

Unified QuickRN design system

A shared brand stylesheet now harmonizes typography, clinical navy and teal accents, focus states, form controls, and interface chrome across the landing page, dashboard, calendar, study modes, exam simulators, saved questions, reports, profile, help, and reference view. NCLEX split-screen layouts and clinical status feedback remain intact.

Simplified Client Needs performance

Combined the separate weak-area and mastery panels into one category list. Red borders identify areas below 75%; neutral borders indicate on-track areas, and dashed borders indicate categories with no attempts. A legend explains each status.

Platform reliability and recovery

Shared browser-storage safeguards, local-only error diagnostics, offline/online notices, cross-tab events, and tab-resume signals are now available across QuickRN. Unfinished exams can be restored after a refresh, with the timer state preserved. Timed exams show five-minute and one-minute warnings. Backup restore validates the complete payload and rolls back a partial write if storage fails.

Safer clinical records

Clinical-record markup is restricted to an allowlist. Executable elements and unsafe attributes are removed before patient-context panels render.

Engineering register

The README records 50 implemented safeguards and subfeatures, plus exam recovery and keyboard shortcuts. Automated regression checks cover the shared platform layer and exam workspace.
