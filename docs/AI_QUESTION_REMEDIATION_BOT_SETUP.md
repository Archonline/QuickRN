# QuickRN AI question-remediation bot setup

The scheduled workflow is `.github/workflows/quickrn-ai-question-remediation.yml`. It runs every 15 minutes and can also be started manually from the GitHub Actions tab.

## One-time repository setup

1. Open **Archonline/QuickRN → Settings → Secrets and variables → Actions**.
2. Under **Secrets**, add `OPENAI_API_KEY` with an API key authorized for the OpenAI Responses API.
3. Optional: under **Variables**, add `QUICKRN_REMEDIATION_MODEL` with the API model name available to the account. If omitted, the worker uses `gpt-6`.
4. Confirm GitHub Actions are enabled and that the workflow has permission to write repository contents.

Do not put the API key in source files, workflow YAML, issues, or commits.

## Current scope and safeguards

- Up to 25 quarantined records are attempted per scheduled run.
- Current supported literal-array source files are batches 004, 007, 008, and 009. The worker refuses to modify source files whose record arrays are generated by a different pattern; batch 005 and batch 006 need a separate generator-aware adapter before they are included.
- The worker preserves question IDs and question format, writes a dated run report under `reports/ai-remediation/`, and does not mark content approved.
- Every proposed revision remains excluded from student use with `reviewStatus: quarantined_content_quality` and `pending_nurse_educator_review`.
- Records that lack enough clinical context are held for source review rather than filled with invented clinical facts.
- This is AI-assisted drafting, not clinical validation. A qualified nurse educator must review every substantive clinical change before release.
- A run with no `OPENAI_API_KEY` makes no content changes and exits without failing the workflow.

## Monitoring

Open **Actions → QuickRN AI question remediation** to inspect scheduled runs, logs, and failures. Each successful run commits its question changes and a dated report to `main`. Review every report and commit; do not promote quarantined items until educator review and the separate quality gates are complete.
